# Vital Apex — site (demonstração)

Site de uma página, estático (HTML, CSS e JavaScript nativos, sem build e sem dependências), com a identidade visual da Vital Apex Health Center. Dois temas (claro e azul profundo, pela preferência do sistema) e movimento em CSS que respeita `prefers-reduced-motion`.

**Esta é uma demonstração.** Os contatos (WhatsApp, endereço e horários) são ilustrativos, o formulário de agendamento não envia dados nem reserva horário, e o site não usa cookies, rastreadores nem requisições externas. Antes de qualquer uso real, faltam a identificação do responsável técnico, o CNPJ e o canal oficial de atendimento. A página pede aos buscadores que não a indexem.

## Como ver localmente

```bash
python -m http.server 4321 --bind 127.0.0.1
```

Abra http://127.0.0.1:4321.
